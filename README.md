# Timer-Cube
A small cube that has a led matrix display that when you flip it to a side, it starts a timer automatically.

My inspiration for this project is this photo
<img width="241" height="237" alt="Screenshot 2026-10-26 092232" src="https://github.com/user-attachments/assets/9584e9c7-ac42-47e1-8c85-f06e86b0decf" />

It is a simple timer that you set by flipping it to a side. After researching components, I settled on the 8x8 square pixel LED matrix and backpack from Adafruit for the display.
I will also be using an ESP32-C3 and MPU6050 to handle code and motion sensing.

I modeled the enclosure which is just a cube with nice fillets and an opening in the front for the display. I am leaving the back open to easily access the components.

I will be using perf board to mount the peices. I wanted to add a battery but ran out of time so it will just be powered though the USB-C connector.
